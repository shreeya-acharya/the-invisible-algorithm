# Invisible Algorithm — Chrome Extension (Sprint 1)

Technical proof of concept for observing visible Instagram Reels captions. It does only one thing: when a visible Reel has a detectable caption, it prints the caption and its hashtags to DevTools Console.

## Structure

```
extension/
├── manifest.json          # Manifest V3 configuration; matches only Reel URLs
├── package.json           # Build/watch commands
├── src/
│   ├── content.ts         # SPA-aware content-script entry point and console logging
│   ├── reel-observer.ts   # Layered DOM selectors and caption detection
│   └── hashtags.ts        # Hashtag extraction
└── dist/content.js        # Generated by the build command (not committed)
```

## Build and load

1. The ready-to-load `dist/content.js` is included, so no build step is required for this proof of concept.
2. In Chrome, open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select the `D:\Projects\extension` folder.
3. Open an Instagram Reel (for example `https://www.instagram.com/reel/...`), open DevTools for that tab, and look in **Console**. Swipe to the next Reel: each newly detected caption is logged once.

To edit the TypeScript sources, first run `npm install` in `D:\Projects`, then build with `npm exec -- esbuild extension/src/content.ts --bundle --format=iife --target=chrome120 --outfile=extension/dist/content.js`. Reload the extension after each build.

## How it works

The Manifest V3 content script runs only for `/reel/` and `/reels/` URLs. It attempts several caption selector strategies inside the visible Reel area, normalizes its text, extracts Unicode-aware `#hashtags`, and logs the required block. A `MutationObserver` watches Instagram's SPA DOM updates and batches them per animation frame, so moving to the next Reel does not require a page refresh. A reel key prevents duplicate logs for the same detected caption.

## Assumptions and limitations

- This observes only text already rendered in the user's browser; it does not call Instagram APIs or infer recommendations.
- Instagram's private DOM changes frequently. The selector list is deliberately layered, but may need adjustment if Instagram changes its accessibility structure or markup.
- Some Reels have no caption, captions may be truncated behind a **more** control, and text that Instagram renders outside the detected Reel container may not be captured. This sprint reports the visible, accessible caption text only.
- The extension does not include a popup, storage, network requests, analytics, AI, authentication, or website/Supabase integration.
